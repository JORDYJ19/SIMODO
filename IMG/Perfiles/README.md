# Fotos de perfil

Coloca aquí una fotografía JPG por cada persona autorizada. El nombre del archivo debe ser el DNI de esa persona seguido de `.jpg`; por ejemplo: `21814585.jpg`.

El sistema muestra la foto después de ingresar el DNI correspondiente. Si el archivo todavía no existe o no se puede cargar, aparece el avatar genérico.
